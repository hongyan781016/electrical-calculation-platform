# V0.7.0 图纸逐回路核验

状态：`0.7.0`阶段收口发布版。后续功能和体验改进进入新版本迭代。

## 本阶段目标

把图纸视为用户提供的既有设计条件，沿“变压器低压出口 → 低压馈线柜 → 末端照明配电箱 → 箱后分支回路 → 末端照明负荷”逐部件核验原设计，不用替代方案覆盖原图结论。

本阶段计算边界已经确认：末端照明配电箱后的分支回路一并计入，不以配电箱进线端作为计算终点。三相上游干线与单相照明分支必须在同一拓扑中分别采用各自相制、导体结构、保护极数和故障回路，不能把单相分支等效成三相YJV线路。

## 已接入核验对象

- 变压器：低压侧电压、uk%输入完整性；单回路负荷与额定电流仅作边界比较，变压器容量结论必须等待全部回路负荷汇总。
- 低压馈线柜、下级配电箱：额定电压、额定电流、短时耐受电流。
- 变压器出口连接段：可选YJV电缆或Canalis KTA 3L+N+PE母线槽。母线槽按精确额定电流及35/40/45/50/55℃查表，统一取得Ue、运行R/X、相-N/相-PE R/X、修正载流量及Icw(1s)，不让用户填写阻抗。
- 原设计干线与箱后分支导体：修正载流量、N/PE配置、累计电压降、相导体与PE热稳定约束；箱后单相BV/BVV分支单独采用相—N及相—PE回路参数。
- 上游、配电箱进线及箱后分支保护器：负荷电流、与受保护导体配合、分断能力、自动切断、相导体及PE热稳定约束。
- 末端负荷：统一推导计算电流并传递到各段。
- 跨部件配合：全回路累计电压降、上下级断路器选择性。

## 判定原则

- 已知条件满足：通过。
- 已知条件明确不满足：不通过。
- 缺少铭牌、产品曲线、I²t、选择性表或全变压器负荷汇总：无法判断，并给出所缺资料或处理要求。
- 原设计核验与独立替代方案分开保存，替代方案不会改变原图的通过/不通过结论。

## 当前边界

- 当前为单电源放射式回路的人工结构化录入；目标拓扑允许上游三相干线在末端照明配电箱后转换为单相照明分支，尚未自动读取DWG。
- 母线槽首批只覆盖施耐德Canalis KTA标准型3L+N+PE（外壳作PE）800～5000A精确表列组合；其他系列、结构或温度不插值。
- 选择性必须使用厂家表和实际整定组合，不能按额定电流大小猜测。
- 变压器容量必须汇总其全部下级回路，单条回路不能形成整台变压器容量合格结论。
- RCD及电动机控制器件只在对应回路声明存在时进入专用核验，不强制添加到普通回路。

## 项目级多回路

- 同一项目可保存多条图纸回路；每条回路独立修订、独立保存不可覆盖结果，修改一条回路不会使其他回路过期。
- 项目页汇总各回路最新有效结果的计算电流。未填写同时系数时只显示算术合计，不猜测上游计算电流。
- 同时系数须由用户填写并记录图纸、设计条件或确认来源；填写后计算上游电流并与同一电源树的变压器低压侧额定电流比较。
- 各回路变压器系列、容量或uk%不一致时，系统拒绝形成同一电源树容量结论。
- 每条回路记录变压器编号、低压母线段编号及馈线柜编号；项目页和成果文件按三级上游归属分别汇总Ib，避免跨母线或跨柜混算。
- 馈线柜、母线段、变压器分别保存本级系数、设备额定电流及来源；本级系数只作用于直接下级汇总，缺少任一级时不越级形成上级结论。项目整体参考同时系数与逐级链相互独立，不重复参与计算。
- 上游设备短路核验按分组内最不利节点取值：馈线柜采用main节点Ikmax，母线段与变压器低压侧采用tx节点Ikmax；分别与柜/母线Icw(1s)及进线断路器Icu比较。选择性只有上下级具体型号/整定、厂家表出处和选择性极限均具备时才判定，不按额定电流大小猜测。
- 项目级完整性总览统计所有当前回路部件、跨部件配合和三级上游设备校核，按“阻断/待补充”生成处理清单。工程数据闭合闸门与正式成果发布闸门分开：即使暂算数据闭合，只要单回路正式状态未通过，也不显示可正式发布。
- 项目级PDF和Excel用于总览；单回路PDF和Excel保留逐部件、逐节点和依据快照细节。

## 末端照明分支验收

- 通用图纸核验入口已经支持“上游三相干线＋末端单相照明分支”，不再把箱后分支强制建模成三相YJV。
- 图纸标注的末端照明箱进线`Ijs`可作为上游各段负荷流；箱后分支电流由单相220V负荷单独计算。监管仓库样例采用47.6A与0.48kW、cosφ=0.8，末端分支电流为2.727273A。
- `YJV 4×S＋1×SPE`按“四根等截面L1/L2/L3/N＋独立PE”表达；箱后BV/BVV按单相L、N＋独立PE表达，图纸明确的PE截面与B/C曲线作为输入，不由相线或器件型号猜测。
- 监管仓库100m馈线＋100m分支回归中，C10保证动作电流为100A，完整链得到末端最小故障电流97.652362A，自动切断判为不通过；上级CM3没有准确脱扣曲线时保持无法判断。
- 同一真实链路已通过项目保存、不可覆盖版本、PDF计算书和Excel成果导出回归。
- 末端照明配电箱进线断路器已经作为独立部件核验，不与上级馈线保护或箱后分支保护混用；三级保护顺序固定为“馈线断路器→配电箱进线断路器→箱后分支断路器”，形成两组选择性证据检查。
