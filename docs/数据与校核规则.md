# 数据与校核规则

## 1. 数据分层

### 项目输入

由具体项目产生，如房间面积、用水点、管段流量、设备服务范围。

### 设计参数

由设计人员选定，如安全系数、目标流速、使用系数。必须记录采用值，必要时记录选择理由。

### 依据参数

来自已核实的规范、设计手册或其他正式资料。记录资料名称、版本、条文号或页码；正文引用必须以实际文件核对结果为准。

### 厂家数据

来自设备样本或厂家确认资料。记录厂家、系列、型号、样本版本或发布日期，避免不同版本参数混用。

## 2. 字段规则

- 一个字段只采用一个内部标准单位。
- 界面可显示常用单位，但进入计算核心前统一换算。
- 原始输入和换算后数值都应保留。
- “缺失”“不适用”和数值 0 必须区分。
- 枚举值使用固定名称，不使用随意文本。
- 每次输出记录计算模块版本和参数版本。

## 3. 计算校核

每个模块至少进行：

- 必填项校验
- 数值类型校验
- 单位校验
- 合理范围校验
- 公式适用范围校验
- 中间结果校验
- 最终约束校验

发现异常时，应输出明确错误或警告，不自动猜测缺失条件。

## 4. 测试规则

每个模块至少准备：

- 3 个已确认结果的正常样本
- 1 个临界条件样本
- 1 个错误输入样本
- 1 个极端值样本

结果允许误差、精度和舍入方式要预先定义。若与人工样本不一致，必须查清是公式、参数、单位、精度还是样本本身的问题，不能仅调整结果去“对数”。

## 5. 计算记录

每次正式计算至少保留：

- 项目与对象标识
- 原始输入
- 采用参数
- 参数来源
- 中间过程
- 计算结果
- 最终采用值
- 警告与错误
- 计算时间
- 程序版本

## 6. 正式发布条件

- 计算依据已经核实
- 样本测试全部通过
- 错误输入不会生成误导性结果
- 输出内容可由第三方复核
- 修改计算逻辑后自动重跑全部基准样本
