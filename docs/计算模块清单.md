# 计算模块清单

本清单用于确定范围和优先级，不代表已经核实其中的计算依据。

## 1. 负荷计算

可候选模块：

- 建筑电气负荷计算
- 暖通冷热负荷汇总
- 给排水设计流量计算
- 消防系统设计流量与用水量汇总

统一输出要求：

- 原始输入
- 分项结果
- 同时使用或折减过程
- 设计值
- 采用值
- 关键参数及来源

## 2. 管径计算

可候选模块：

- 生活给水管径
- 排水管径与充满度校核
- 消防给水管径与流速校核
- 暖通水管管径与比摩阻校核
- 风管尺寸与风速校核

统一输出要求：

- 设计流量
- 候选规格
- 实际流速
- 阻力或水力参数
- 是否满足约束
- 最终采用规格及取值说明

## 3. 设备选型

可候选设备：

- 水泵
- 风机
- 空调机组
- 换热设备
- 水箱
- 消防相关设备
- 电气设备

选型过程分为两层：

1. **计算需求**：流量、扬程、功率、冷热量、风量等设计需求。
2. **设备筛选**：从设备库筛掉不满足硬性条件的型号，再按余量、效率等指标排序。

选型结果至少显示：

- 设计需求
- 设备额定参数
- 设计工况参数
- 余量
- 不满足项
- 厂家、系列、型号
- 样本名称、版本或日期

## 4. 跨模块公共能力

- 单位换算
- 数值精度和舍入规则
- 输入范围与缺失值检查
- 参数来源记录
- 计算过程日志
- 项目信息和基础数据复用
- Excel/CSV 导入导出
- 计算书生成
- 基准样本自动比对

## 5. 模块接口模板

每个模块开发前填写：

```text
模块名称：
适用范围：
不适用范围：

输入：
- 字段 / 单位 / 必填 / 合法范围 / 来源

参数：
- 名称 / 数值或取值方法 / 来源 / 版本

计算过程：
- 步骤 / 中间值 / 单位

输出：
- 计算值 / 采用值 / 校核项 / 提示

测试样本：
- 正常样本
- 临界样本
- 错误输入
- 极端值
```
