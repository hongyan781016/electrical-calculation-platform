# 0.4kV回路计算平台实际可用化实施方案

日期：2026-08-01
状态：执行方案
目标：让有电气基础的用户能完成“变压器低压出口至一个线路末端”的一次录入、计算、复核和归档，而不需要在平台外重复整理计算数据。

## 1. 什么叫“实际可用”

不是页面能出数，也不是只展示电缆或断路器候选。一个回路只有同时满足以下条件，才可标记为“计算链闭合”：

1. 图纸或用户确认的供电拓扑明确：变压器低压端、各级柜/箱、线路段、末端负荷；
2. 每段线路都有型号、芯数/PE结构、长度、敷设条件和修正条件的来源或明确的设计输入标记；
3. 每个保护点都有安装位置、额定值、极数/N极方式，以及可核验的分断、脱扣和配合资料；
4. 计算链输出负荷电流、电缆、断路器、累计压降、各节点最大短路电流、线路末端最小故障电流、分断能力、自动切断和热稳定；
5. 每项结果均可回链到输入快照、规则版本、资料页码或厂家样本；缺失项只能显示“无法判断”，不得被候选值掩盖；
6. 同一输入在页面、导出和回归测试中得到一致结果。

规则未批准时，以上只能作为“暂算闭合”；不得升格为正式设计结论。

## 2. 用户工作流

```text
选择图纸/项目
  → 确认系统识别出的变压器至末端路径
  → 仅补齐图纸没有的设计条件
  → 系统查本地资料库/厂家资料补齐设备参数
  → 一键计算与组合筛选
  → 查看推荐组合、淘汰原因、待确认项
  → 保存版本并导出计算书
```

简单单回路保留“快速计算”入口，不要求图纸或项目；它只解决从负荷到末端保护器件的初选。完整回路入口才从变压器低压出口起算。

## 3. 交付顺序

### 阶段A：单回路可交付

把现有`/quick`从“演示可算”收紧为可复核的单回路初选：

- 固定普通负荷、照明、插座三类适用边界；
- 输入负荷、相制、电压、长度、线路型号/敷设；
- 输出计算电流、电缆候选、断路器设计参数、电压降和完成状态；
- 有明确变压器/线路资料时接入短路、TN故障和热稳定；其中相导体热稳定采用被保护线路起点最大三相短路电流，PE热稳定采用相—PE故障电流，两者均必须使用实际切除时间或产品I²t；
- 将每个候选的依据、采用值和缺失校核集中展示；
- 以手算样例和边界样例验收。

**验收**：用户在不建项目、不导入Excel的情况下完成一个普通末端回路；输入、结果和警告可导出且可复算。

### 阶段B：变压器至末端的完整回路

- 将图纸路径转换为`CompleteCircuit`，而非要求用户录入R/X；
- 建立“图纸字段→设备/线路/负荷”的确认页；
- 对图纸缺失的厂家参数，建立检索、下载、来源登记和人工确认流程；
- 接通既有完整回路计算内核与电缆—断路器组合求解器；
- 按线路段累计压降、节点最大短路、末端最小故障电流与保护校核输出；
- 使用宣城保税区监管仓库样例进行端到端验收。

**验收**：补齐经确认的设计输入后，系统从B1低压端到WL1生成同一版本的组合结果；任一上游参数改变，下游结果全部失效并要求重算。

### 阶段C：成果归档

- 将完整回路输入、资料版本、计算过程和结果写入SQLite；
- 提供PDF计算书和Excel成果；
- 导出中逐项列出依据、输入性质、缺失项和暂算/正式状态；
- 用真实回路、手算样例及错误输入做一致性验收。

**验收**：一个工程无需平台外重复录入，即可复算、留档和导出。

## 4. 目前必须补齐的数据能力

| 数据 | 优先来源 | 作用 |
|---|---|---|
| 变压器铭牌/厂家数据 | 图纸、铭牌、厂家样本 | 短路网络和故障回路 |
| 上级系统短路边界 | 图纸、供电资料、设计条件 | 最大/最小短路电流 |
| 电缆结构、载流量、R/X、修正条件 | 已核验图集/手册、厂家资料 | 截面、压降、短路、故障回路 |
| 断路器曲线、Icu/Ics/Icw、I²t、选择性表 | 图纸型号后查厂家样本 | 分断、动作、热稳定、选择性 |
| RCD额定动作参数和类型 | 图纸型号后查厂家样本 | 人身/火灾故障保护 |
| 线路长度、敷设、环境/成组 | 图纸、清册、用户设计输入 | 压降及载流量修正 |

“用户设计输入”是允许的数据来源，但必须与“图纸/铭牌/厂家原始资料”分开保存和显示。

## 5. 本轮执行方式

采用单主会话顺序开发，不采用长期多会话拆分。

原因：当前任务依赖同一数据模型、规则目录、页面与真实样例，前后顺序强；此前多会话出现权限反复确认、上下文重复和交接成本高于并行收益。只有厂家资料的独立查找或单次审查任务边界稳定时，才临时拆分，且不同时修改代码文件。

## 6. 下一步唯一主线

先完成阶段A的端到端验收：梳理现有单回路页面的输入、计算结果和缺失项，使其成为可交付的普通回路初选；然后用同一输入模型承接阶段B，不再另建一套“完整回路演示表单”。
