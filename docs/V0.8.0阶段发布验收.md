# V0.8.0 电气图纸辅助识别阶段发布验收

状态：`0.8.0`发布候选。

## 发布范围

- 只读接入DWG、ASCII DXF及带文字层PDF；二进制DWG通过本机AutoCAD Core Console处理临时副本，原图不保存；
- 保存文件哈希、CAD实体句柄、图层、块属性、坐标或PDF页码等原始证据；
- 按标题栏图号、配电箱表头和水平回路行形成空间分组，生成变压器、低压进线、馈线、配电箱、分支回路和部件参数候选；
- 候选必须经用户逐项确认；弱证据、冲突及缺失项不得静默进入计算；
- 确认结果以不可覆盖修订保存，图纸或确认变化后旧确认及关联计算自动失效；
- 已确认字段单向适配到V0.7确定性完整回路内核，支持项目保存及版本级PDF、Excel导出；
- 只有图纸明确标注“4极直接启动”或`DOL`时才生成直接启动电动机候选，模糊设备用途不推断启动方式。

## 明确边界

- 不修改原始图纸，不上传云端；
- 不承诺任意制图习惯下的零确认识别；
- 不从系统图图形距离推断实际线路长度；
- 不以相近设备名称、空间邻近或识别置信度替代明确拓扑证据；
- 不在图纸模块复制负荷、电压降、短路、故障保护、热稳定或选择性公式；
- 星三角、软启动、变频器及多专业图纸审查不属于本版。

## 发布验收

- 匿名端到端链路：上传图纸 → 选择单行回路 → 逐项确认 → 完整回路计算 → 项目保存 → PDF/Excel导出；
- 普通照明链路及明确标注的4极直接启动电动机链路均已覆盖；
- 项目真实DWG仅用于本地只读验收，不进入公开仓库；
- Edge桌面版及侧栏窄屏布局实测正常；
- 全量测试：391项通过；
- `compileall`、`git diff --check`及敏感凭据扫描通过；
- 第三方`StarletteDeprecationWarning`不影响本版功能，后续依赖升级时处理。

## 发布文件边界

公开提交仅包含源码、匿名测试、依赖清单及公开说明。以下内容继续排除：

- 真实工程DWG、BAK及其提取缓存；
- 规范、设计手册、厂家样本原件；
- 当前任务、阶段交接和项目长期记忆；
- 本地数据库、导出成果、临时目录及个人绝对路径。
