# 需求与路线图

## 一、要解决的问题

目前常见工程计算通常存在以下重复工作：

- 同类项目反复建立计算表
- 基础数据在多个表格之间重复录入
- 公式、单位、舍入方式不统一
- 修改输入后容易漏改关联结果
- 计算结论缺少完整过程，复核成本高
- 设备选型依赖人工翻样本、逐项比较

本项目的重点不是“把所有设计工作做成软件”，而是先固化重复、稳定、可验证的计算环节。

## 二、使用场景

### 场景 1：单项快速计算

设计人员输入少量条件，立即得到计算结果、关键中间值和风险提示。

### 场景 2：项目批量计算

从标准 Excel/CSV 导入房间、管段或设备需求，批量计算并输出汇总表。

### 场景 3：设备初选

读取计算需求，从已维护的设备库中筛选满足条件的型号，并显示余量、超配程度及被排除原因。

### 场景 4：设计复核

导入已有数据，检查单位、输入范围、计算结果和设备参数是否存在明显异常。

## 三、范围边界

### 纳入首期

- 高频单项计算
- 批量数据导入与结果导出
- 单位换算和输入校验
- 计算过程记录
- 参数来源记录
- 基础设备筛选
- 已知样本回归测试

### 暂不纳入

- 自动完成整套专业设计
- 自动解读或改写规范条文
- BIM/CAD 深度联动
- 多人在线协同
- 自动抓取厂家网站数据
- 未经人工确认直接替代设计结论

## 四、版本路线

### V0：需求固化与样本准备（约 2～3 天）

交付物：

- 确定第一个计算模块
- 收集 3～5 份已完成、可确认正确的人工计算样本
- 列出输入、输出、中间过程、异常条件
- 建立参数来源清单
- 统一字段命名和单位

退出条件：不看原计算表，也能根据需求说明复现该计算。

### V0.1：单模块最小可用版（约 1 周）

交付物：

- 单项计算核心
- 输入校验与单位处理
- 计算过程展示
- Excel/CSV 输入输出
- 自动化测试
- 简单计算书

退出条件：所有基准样本结果一致；边界条件有明确提示。

### V0.2：批量计算与项目复用（约 1 周）

交付物：

- 批量导入模板
- 多对象连续计算
- 项目基础信息复用
- 汇总表和错误清单
- 计算结果版本标识

退出条件：能处理一个真实项目的数据，并能定位每一条失败记录。

### V0.3：设备初选（约 1～2 周）

交付物：

- 设备数据模板
- 硬性条件筛选
- 余量与超配排序
- 筛选原因说明
- 厂家样本来源和日期记录

退出条件：每个推荐型号都能解释“为什么满足、余量多少、数据来自哪里”。

### V1：扩展计算模块

按“使用频率 × 节省时间 × 规则稳定性 × 可验证性”排序，逐个增加模块。每增加一个模块，都沿用 V0.1 的验收标准，不批量堆功能。

## 五、首批任务

| 优先级 | 任务 | 产出 |
|---|---|---|
| P0 | 选定第一个计算模块 | 一句话范围定义 |
| P0 | 收集正确样本 | 3～5 份输入与结果 |
| P0 | 拆解计算过程 | 输入/公式/中间值/输出清单 |
| P0 | 核实依据 | 参数来源、版本、页码或样本页 |
| P0 | 定义统一单位 | 字段与单位表 |
| P1 | 编写计算核心 | 可独立调用的函数 |
| P1 | 建立回归测试 | 样本结果自动比对 |
| P1 | 制作导入模板 | Excel/CSV 模板 |
| P1 | 输出计算书 | 可复核、可归档 |
| P2 | 建立设备库 | 厂家参数标准表 |

## 六、优先级评分

候选模块按下表打分，每项 1～5 分：

| 维度 | 权重 | 说明 |
|---|---:|---|
| 使用频率 | 30% | 日常出现次数 |
| 单次耗时 | 25% | 当前人工耗时 |
| 规则稳定 | 20% | 公式和边界是否明确 |
| 容易出错 | 15% | 单位、抄录、联动错误风险 |
| 样本齐全 | 10% | 是否有可靠样本用于核对 |

总分最高的模块优先，不以技术难度或界面效果作为首要依据。

## 七、阶段验收指标

- 单项计算时间比原流程减少 70% 以上
- 基准样本结果一致率 100%
- 所有正式参数均能追溯来源
- 无效输入不会静默生成结果
- 计算书能让另一位工程师独立复核
- 修改输入后，所有关联结果自动刷新

## 八、当前待确定事项

开始开发前只需要确认三件事：

1. 第一个模块具体是什么。
2. 现有可靠计算表或手算样本在哪里。
3. 最常用的成果形式是 Excel 表、计算书，还是两者都要。
