# V0.2 电动机回路实施方案

日期：2026-08-10

## 1. 阶段目标

在现有完整低压放射式回路基础上，增加一个真正可用的电动机末端回路入口。用户提供通常能够取得的铭牌和线路条件，平台自动完成：

```text
电动机铭牌功率/电流
→ 额定运行电流
→ 启动电流
→ 电缆候选
→ 运行及启动电压降
→ 短路保护候选
→ 接触器候选参数
→ 热继电器候选参数
→ 短路、接地故障和导体热稳定复核
```

本阶段输出仍分为“通用设计参数候选”和“具体产品核验”。没有厂家目录证据时，不输出品牌型号。

## 2. V0.2.0 纳入范围

- 0.4kV、50Hz、三相低压交流异步电动机；
- 单台电动机、单独末端回路；
- 直接启动；
- 铜芯BV/YJV线路，复用现有载流量、压降、短路、接地故障和热稳定内核；
- 已知额定功率kW或铭牌额定电流A；
- 断路器短路保护主路径；
- 接触器AC-3使用类别候选；
- 热继电器过载保护候选；
- 运行电压降和启动电压降分别计算；
- 图纸核验与快速选型继续分离。

## 3. 暂不纳入

- 单相电动机；
- 星三角、自耦降压、软启动器、变频器启动；
- 多台电动机成组及干线需要系数；
- 频繁正反转、点动、反接制动、起重冶金等特殊工作制；
- 高压电动机；
- 无具体产品资料时的选择性、级联和后备保护正式结论；
- 用新产品参数反推现场旧设备合格。

上述内容按V0.2.1及以后版本逐项增加，不在V0.2.0中预埋大量用户输入框。

## 4. 数据责任

### 4.1 用户必须提供或确认

| 数据 | 最少要求 | 说明 |
|---|---|---|
| 铭牌额定功率或额定电流 | 二选一 | 铭牌电流优先于计算值 |
| 额定电压 | 默认380V，可改 | 必须与设备铭牌一致 |
| 电动机相制 | V0.2.0固定三相 | 不让用户重复选择无效选项 |
| 启动方式 | V0.2.0固定直接启动 | 页面明确显示阶段边界 |
| 启动频繁性 | 频繁/不频繁/不清楚 | 用于自动采用启动时母线电压限值；不清楚时只作保守初选 |
| 同母线负荷情况 | 有照明或敏感负荷/无此类负荷/无其他负荷/不清楚 | 用于自动采用启动时母线电压限值 |
| 线路长度 | m | 用于运行及启动压降、故障阻抗 |
| 导体型号及敷设场景 | BV/YJV及适用场景 | 继续由目录过滤不适用组合 |
| 环境及成组条件 | 知道时填写 | 缺失时保留基础候选并标明未闭合 |
| 变压器/上级电源条件 | 完整回路模式必填 | 快速模式可只输出未完成短路校核 |

### 4.2 系统优先推导

- 功率输入时，根据已核实的功率因数和效率取得额定电流；
- 铭牌电流存在时直接采用，不再用功率反算覆盖；
- 按启动方式及已核实参数取得启动电流或范围；
- 按上级电源、变压器、母排/干线和末端电缆组成的网络阻抗，分别计算启动时配电母线电压和电动机端子电压；
- 按启动频繁性和同母线负荷情况自动取得启动时配电母线电压限值，不让用户填写百分比；
- 复用现有网络模型计算安装点最大短路电流、末端最小短路/接地故障电流；
- 按选定保护器候选的实际脱扣或整定参数完成动作校核；
- 根据电流、使用类别和产品目录筛选接触器；
- 根据电动机铭牌电流和产品调节范围筛选热继电器，并给出整定目标；
- 所有自动值标记为“计算推导”“资料查表”或“产品目录”，不得标成用户确认。

### 4.3 只能查表或查产品样本

- 电动机功率因数、效率的适用表及边界；
- 直接启动电流倍数或具体铭牌/样本参数；
- 允许启动压降及适用条件；
- D型MCB的保证动作边界；
- MCCB电动机保护脱扣器的整定范围和动作特性；
- 接触器AC-3额定工作电流/功率及电寿命适用条件；
- 热继电器调节范围、脱扣级别、缺相保护等参数；
- 熔断器类别与配合参数（后续支路）。

### 4.4 不能可靠取得时

输出“无法判断”和具体缺项，不要求普通用户填写I²t、Ia、脱扣曲线坐标、接触器寿命曲线等专业数据。

## 5. 模块边界

### 5.1 `motor_load`

负责铭牌条件、运行电流和启动电流，不选择任何产品。

### 5.2 `motor_cable`

复用通用电缆候选，增加启动电压和电动机保护配合约束。电缆截面必须同时满足载流量、运行压降、已适用的启动电压校核、故障保护和热稳定。

### 5.3 `motor_short_circuit_protection`

输出断路器所需的额定电压、额定电流/整定范围、壳架等级、分断能力和瞬时/短延时动作边界。D型MCB与MCCB必须按各自依据处理，不得把D型倍数套用于MCCB。

### 5.4 `motor_contactor`

按AC-3使用类别、额定工作电压和电动机工作电流/功率筛选。线圈电压属于控制回路条件，不从主回路电压直接猜测。

### 5.5 `motor_overload_relay`

按铭牌电流、调节范围、脱扣级别和配合接触器筛选。热继电器负责过载保护，不代替短路保护。

### 5.6 `motor_combination`

只组合已经独立通过的电缆、短路保护器、接触器和热继电器候选，并列出每个组合的淘汰原因及未完成校核。

## 6. 计算与选型顺序

1. 校验铭牌输入和适用范围；
2. 取得额定运行电流；
3. 取得启动电流或保守范围；
4. 生成电缆基础候选并完成修正载流量；
5. 校核运行电压降；
6. 校核启动时配电母线电压；必要时进一步校核电动机端子电压和启动转矩；
7. 计算各节点最大/最小短路与接地故障电流；
8. 生成短路保护候选并校核分断和保证动作；
9. 生成接触器候选；
10. 生成热继电器候选；
11. 校核相导体与PE热稳定；
12. 输出满足全部已知硬条件的组合及未闭合项目。

任何后级候选都不得绕过前级条件直接给出“推荐型号”。

## 7. 资料准备

优先从项目现有资料中核验：

- 《工业与民用供配电设计手册（第四版）》：电动机电流、启动、电压降和保护配合方法；
- `19DX101-1建筑电气常用数据国标图集.pdf`：电动机保护用断路器通用参数，以及CJ20接触器、JR20热继电器历史产品参数；不将后两表当作现代通用产品目录；
- `规范大全-2025.12.7b.chm`：本阶段采用标准正文；
- `微机电动机保护装置整定计算.xls`：仅作公式结构和回归结果对照，不作为正式依据；
- 制造商原始样本：D型MCB/MCCB、接触器、热继电器；取得具体系列后按型号下载，不批量导入。

首轮编码前必须形成规则核验表：依据编号、表号/条文号、原文、页码、适用条件、状态。未核实规则不得进入计算。

## 8. 验收标准

- 典型三相电动机kW输入可生成完整过程链；
- 铭牌电流输入不受功率因数和效率影响；
- 功率输入只在有已核实功率因数和效率时计算；
- 启动电流与运行电流分别显示且来源清楚；
- 电缆必须同时通过运行载流量、运行压降和已适用的启动电压校核；
- 启动时配电母线电压与电动机端子电压分开显示，不用一个“启动压降”结果替代两个节点；
- 断路器分断能力、保证动作和电缆热稳定分别校核；
- 接触器采用AC-3目录，不按断路器额定电流简单等同；
- 热继电器调节范围覆盖铭牌电流，整定值有明确来源和状态；
- 缺少上游短路或产品曲线时仍可显示已完成候选，但正式状态为“无法判断”；
- 图纸核验保留原产品结论，替代候选单独输出；
- 页面只显示普通用户必须确认的条件，专业参数默认自动推导或折叠；
- 现有263项测试继续通过，并增加电动机单元、组合、网页和完整回路回归测试。

## 9. 开发顺序

1. 逐页核验电动机负荷电流、启动电流及启动压降依据；
2. 建立电动机结构化输入输出和纯计算引擎；
3. 接入现有电缆和完整回路内核；
4. 核验并建立断路器、接触器、热继电器产品参数目录；
5. 建立组合求解器；
6. 增加独立的电动机快速页或快速页电动机分支；
7. 完成页面、导出和真实样例验收；
8. 冻结边界并发布V0.2.0。

当前步骤3已完成一段式网络和逐电缆复算；步骤4已先完成不绑定品牌的断路器硬条件。实际脱扣器目录、时间—电流曲线、接触器与热继电器产品配合仍未完成。

## 10. 会话组织评估

本阶段继续采用单主会话顺序开发，不建立02/03/04长期会话：

- 规则核验、数据模型、电缆复用和保护组合存在强串行依赖；
- 会同时触及完整回路领域模型、目录、组合器、页面和测试；
- 过去多会话出现反复授权、上下文重复、接口错位及David不可见的问题；
- 预期协调成本大于并行收益。

只有在产品样本已确定、文件边界稳定时，才可临时增加一个只读审查任务；该任务不得修改共享代码。出现授权或上下文问题时立即退出，回到单主会话。
