# V0.4 项目归档与成果输出实施方案

日期：2026-08-12

## 阶段目标

将V0.3可填写的完整低压放射式回路接入项目库，使一次工程计算能够保存、复算、追溯并形成可交付成果。导出必须直接消费不可覆盖的版本快照，不在PDF、Excel或页面中重复计算。

## 实施范围

1. 每个项目保存一个当前完整回路输入；
2. 输入内容变化时递增网络修订号，并标记旧计算版本过期；
3. 每次计算形成不可覆盖记录，冻结输入、推导值、原设计核验、主方案、警告和依据；
4. 项目页显示当前回路、修订号、历史版本及过期状态；
5. 历史版本可单独查看；
6. 每个版本导出PDF计算书和Excel成果表；
7. 旧版单回路项目、历史和导出接口保持兼容。

## 数据边界

- `project_networks`：项目当前完整回路、内容哈希、修订号和最近变化字段；
- `network_calculation_runs`：不可覆盖的版本记录；
- 相同输入重复保存不增加网络修订；
- 任一输入字段改变后，旧完整回路版本全部标记为过期；
- 当前首版采用整网重算，不做局部缓存，但计算链内部仍按同一网络数据处理上下游影响。

## 成果内容

PDF与Excel均包含：

- 项目和版本信息；
- 用户输入及系统推导值；
- 主电缆和保护器件参数；
- 逐节点累计电压降、短路和接地故障结果；
- 既有设计模式下的原部件独立结论；
- 警告、未闭合项及规则依据快照；
- 正式状态、暂算状态和是否过期。

## 当前限制

- 一个项目只维护一个当前放射式完整回路；
- 暂不提供多个完整回路树、项目复制、版本删除或回滚；
- 暂不自动解析DWG；
- 暂不把规范原件嵌入成果文件；
- 未批准依据仍只能形成暂算结果。

## 验收要求

- 保存V1后修改负荷并保存V2，V1必须保留且标记过期；
- V1与V2输入快照互不覆盖；
- 页面、PDF和Excel来自同一版本记录；
- PDF逐页渲染无截断、重叠或缺字；
- Excel各工作表可读，无公式错误；
- 旧版数据库可幂等升级，新旧项目页面和接口继续可用；
- 全量自动测试通过。

## 多会话评估

本阶段不使用多会话。数据库迁移、版本服务、网页和导出共享同一快照结构，依赖高度串行且会修改同一组文件；拆分会增加接口错位、重复读取和文件冲突。采用单主会话连续实施，只有后续独立的模板视觉审查可临时分离。若出现重复授权、上下文重复或总Token增加，继续保持单会话，不为形式上的并行增加协调成本。
