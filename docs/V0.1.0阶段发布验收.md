# v0.1.0 阶段发布验收

## 阶段目标

交付一个可在 Windows 本机独立运行的低压完整单回路计算版本。以图纸中的完整放射式链路作为结构参照，从变压器低压出口、低压柜、配电回路一直计算到用电设备末端。

真实工程图纸仅作为端到端验收夹具，不是产品功能任务，也不作为公开仓库数据发布。

首版包含两个用途明确分离的工作流：

1. **图纸核验**：图纸是用户提供的项目条件。系统复算图纸已有的变压器、线路和保护器件，逐项判断原设计是否合规；原器件结论与替代设计必须分开。
2. **快速计算**：用户只提供功率或电流、相制、长度等最少条件。系统自动查表和推导，输出便于采购的电缆、断路器等通用规格参数，不绑定品牌型号。

两个工作流共享计算公式、参数目录和校核模块，但输入来源、证据状态和结果语义不得混用。

## 本阶段纳入范围

- `/quick` 作为末端负荷和线路条件的简易录入入口；
- 图纸条件形成的既有回路核验入口；
- 变压器低压出口、低压总柜、分配电箱和用电设备的有序拓扑；
- 单相、三相普通照明和动力回路；
- kW、kVA、已知电流三种已知量；
- 各线路段负荷电流和采用参数来源；
- 各线路段 BV、YJV 铜导体基础载流量初选及已实现的敷设修正；
- 各保护安装点不绑定品牌的断路器设计参数候选；
- 图纸已有器件按原规格独立复核，并输出通过／不通过／无法判断；
- 各段及末端累计电压降，并按回路用途采用规则限值；
- 各节点最大三相短路电流、最小相—N短路电流和 TN 相—PE接地故障电流；
- 断路器额定电流、分断能力、自动切断条件，以及相导体和PE热稳定约束；
- 上下级保护存在精确厂家配合表时作选择性判定；没有时明确保持“无法判断”；
- 缺失参数、依据状态和未完成校核必须明确显示，不猜测正式结论；
- 快速计算不创建项目、不写入计算历史。

## 本阶段不作为验收条件

- 电动机专用的接触器、熔断器、热继电器及 D 型 MCB/MCCB 整定；
- 多变压器、环网、母联、备用电源和复杂网状系统；
- DWG 自动解析和跨图纸拓扑识别；
- 项目历史、Excel 批量导入、PDF/Excel 成果作为首版主流程；
- 缺少厂家选择性或后备保护表时自动给出选择性结论；
- 将未批准规则或测试样例提升为正式工程结论。
- 用替代产品的合格结论反推图纸原器件合格。

上述已有试验性代码可以保留，但不在 v0.1.0 的产品承诺内。

## 发布验收条件

1. 新环境按 README 可完成安装和启动，完整单回路入口正常。
2. 匿名验收链路包含“变压器低压出口 → 低压柜 → 分配电箱 → 用电设备”，并由同一编排入口一次计算完成。
3. 每个节点输出累计阻抗、最大/最小故障电流；每段输出负荷流、载流量和电压降。
4. 每个保护点输出额定电流与分断能力要求、自动切断状态；每条线路输出相导体与PE热稳定状态。
5. 页面只要求用户填写其能够知道的项目条件；可查表或可推导参数由系统产生，并显示来源。
6. 图纸核验结果明确区分“原设计复核”和“替代设计”；快速计算结果明确标注“通用规格候选”。
7. 页面结果、计算引擎结果及测试断言一致。
8. 全套自动化测试通过。
9. Git 提交中不包含真实 DWG、规范原件、产品资料、客户名称、文件哈希、项目交接和长期记忆。
10. README 明确标注“暂算/初选”边界及后续版本路线。

## 后续版本顺序

1. `v0.2`：电动机回路及接触器、熔断器、热继电器选型。
2. `v0.3`：复杂多回路、母联和备用电源网络。
3. `v0.4`：项目保存、历史复算和版本失效管理。
4. `v0.5`：Excel 批量导入、PDF 计算书和 Excel 成果归档。

版本编号可在实施时调整，但每个阶段必须先完成范围冻结、测试、脱敏和发布，再进入下一模块。
