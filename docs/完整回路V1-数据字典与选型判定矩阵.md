# 完整回路 V1：数据字典与选型判定矩阵

版本：0.2
日期：2026-08-01
状态：开发输入文件，不是规范依据或正式计算书

## 1. 目标

完整回路 V1 解决一个固定的 0.4kV 放射式回路：

```text
变压器低压端
→ 低压连接段（母线槽或电缆，也可无）
→ 总配电柜
→ 干线
→ 分配电箱
→ 末端线路
→ 普通用电设备
```

平台应根据一次录入的电源、线路、负荷和环境条件，完成：

1. 负荷电流计算；
2. 断路器参数候选生成；
3. 导体结构和截面候选生成；
4. 修正载流量校核；
5. 从变压器低压端起算的累计电压降校核；
6. 各保护安装点最大预期短路电流计算；
7. 各线路末端最小短路或接地故障电流计算；
8. 分断能力、自动切断和导体热稳定校核；
9. 电缆与保护器件组合迭代；
10. 输出推荐组合、淘汰原因、缺失条件和依据状态。

平台的最终推荐对象是一个组合，而不是彼此孤立的设备：

```text
回路负荷
+ 线路各段导体结构与截面
+ 各级断路器设计参数
+ N、PE配置
+ 电压降结果
+ 最大和最小故障电流
+ 保护配合结果
```

## 2. V1 范围

### 2.1 纳入范围

- 额定电压为 0.4kV 等级的低压放射式系统；
- 单台变压器、单电源；
- TN-S 或 TN-C-S，TN-C-S 的 N/PE 分开点必须明确；
- 铜芯 BV、YJV；
- 单相或三相普通负荷；
- 照明终端、插座终端、普通非电动机设备终端及配电干线采用各自的选型策略；
- 一段可选的变压器低压连接段；
- 一段干线和一段末端线路；
- MCB、MCCB、ACB 的通用设计参数模式；
- 已有具体产品的核验接口预留；
- 不绑定品牌的设计参数输出。

### 2.2 暂不纳入

- 变压器并联；
- 双电源、发电机、UPS和自动转换；
- 环网；
- 并联电缆；
- 母线分段和母联运行方式组合；
- 电动机启动、接触器、热继电器及电动机专用保护配合；
- 谐波导致的中性线和载流量专门计算；
- 10kV 侧设备选型；
- 上下级保护的完整时间—电流曲线选择性计算；
- 自动绑定厂家和产品型号。

遇到以上条件时不得简化套算，应返回“不适用”或“无法判断”。

### 2.3 用户界面固定流程

完整回路页面不得把计算内核字段、R/X、保护曲线或规则编号直接作为首屏录入项。用户工作流固定为：

1. **确认图纸识别结果**：系统从图纸取得变压器、总柜、配电箱、线路、负荷及已有保护器件；用户只确认起点和目标末端。
2. **补充设计条件**：仅显示图纸未给出、但本次计算需要的字段，例如各段线路长度、敷设条件和负荷实际工况。用户输入的长度必须标记为“设计输入／待现场核实”。
3. **自动补齐资料**：图纸未标明的设备型号参数，优先从厂家样本或可追溯资料库查询；查不到时才列为待确认，不要求用户先手填内部计算参数。
4. **一键整链计算**：按本文件第8节的闭环顺序运行，统一输出电缆和断路器组合、压降、最大/最小短路电流、接地故障与保护校核。

用户首屏只应看到“图纸识别是否正确”“还要补什么”“计算结论”。R/X、温度折算、故障回路和产品曲线只在计算过程与待确认项中展开。

## 3. 架构边界

### 3.1 四个独立层次

| 层次 | 职责 | 禁止事项 |
|---|---|---|
| 回路模型 | 保存节点、线路段、负荷、保护位置和拓扑 | 不执行选型 |
| 计算内核 | 计算电流、R/X、压降、短路和故障电流 | 不查询产品型号 |
| 候选生成器 | 按硬条件生成电缆或断路器设计参数候选 | 不直接宣布最终通过 |
| 组合校核器 | 对“电缆＋断路器＋回路条件”逐组校核和排序 | 不补猜缺失输入 |

### 3.2 规则、目录和项目输入分离

| 数据类型 | 示例 | 变更方式 |
|---|---|---|
| 项目输入 | 变压器铭牌、线路长度、环境温度 | 用户录入或项目导入 |
| 计算派生值 | 计算电流、累计R/X、末端故障电流 | 计算引擎生成 |
| 规则 | 公式、适用条件、判定关系 | 规则库版本化 |
| 通用参数目录 | 断路器设计参数档位、电缆表列参数 | 按资料版本维护 |
| 产品参数目录 | 某厂家某型号的Icu、曲线、I²t | 仅用于具体产品核验 |

只有状态为“已批准”的规则和参数才能改变正式结论。已核实但未批准的数据可以产生暂算结果。

| `neutral_section_mm2` | mm² | 条件必填 | 用户/结构目录 |

线路段不得由“相制”自动推定芯数、N、PE或PEN配置。

### 4.4 `SegmentLoadFlow`

同一条电源到末端的路径中，各线路段承载的下游汇总负荷可能不同，
不得把末端设备电流直接套用于所有上游线路段。

| 字段 | 类型/单位 | 必填 | 来源 |
|---|---|---:|---|
| `segment_id` | 标识 | 是 | 系统 |
| `design_current_a` | A | 是 | 该段下游负荷汇总计算 |
| `power_factor` | 1 | 是 | 该段下游负荷汇总计算 |
| `phase` | 枚举 | 是 | 本段实际负荷流为单相或三相均衡 |
| `source_reference_ids` | 标识列表 | 是 | 负荷汇总计算记录 |

- 末端线路的负荷流对应末端负荷；
- 干线和变压器连接段的负荷流来自该段全部下游负荷汇总；
- 三相线路允许承载单相分支形成的负荷流，但必须明确相别和负荷分配；
- 单相线路不能承载三相负荷流；
- 电压降使用各段自己的负荷流；
- 短路和接地故障计算使用物理线路阻抗，不受正常负荷流替代。
- 末端线路负荷流必须与末端负荷计算结果闭合；不一致时停止组合校核。
- 相—N短路只在线路结构实际连续配置N导体时计算；没有N导体应标记为“不适用”，不能标记为“缺少参数”。

### 4.5 `Load`

| 字段 | 类型/单位 | 必填 | 说明 |
|---|---|---:|---|
| `input_basis` | 枚举 | 是 | kW、kVA、A |
| `input_value` | 对应单位 | 是 | 总输入值 |
| `phase` | 枚举 | 是 | 单相、三相 |
| `load_type_code` | 枚举 | kW时条件必填 | 取得适用参数 |
| `power_factor` | 1 | kW时条件必填 | 铭牌优先；否则规则目录 |
| `efficiency` | 1 | 普通负荷否 | 普通负荷不使用 |
| `demand_factor` | 1 | 安装功率汇总时条件必填 | 单回路计算功率不使用 |
| `duty_characteristic` | 枚举 | 是 | 普通连续、间歇、明显冲击等 |
| `circuit_application` | 枚举 | 是 | 照明终端、插座终端、普通设备终端、电动机终端、配电干线 |
| `load_profile` | 枚举 | 是 | 照明、插座、普通设备、电动机、混合配电 |

`circuit_application`与`load_profile`不得合并：

- `circuit_application`决定限值、保护器类别、自动切断和RCD等策略；
- `load_profile`决定功率因数、效率、冲击、谐波和中性线等负荷特性；
- 配电干线可以是混合负荷，不能强制归为照明或动力；
- “动力”不是单一计算类型，必须区分普通非电动机设备和电动机；
- V1先实现照明、插座、普通设备和配电干线策略；电动机可以被数据模型识别，但计算返回“不适用”，待电动机模块接入。

### 4.6 回路用途策略

| 回路用途 | V1状态 | 特有输入和校核 |
|---|---|---|
| 照明终端 | 纳入 | 照明负荷参数、对应电压降规则、单相分配、N线及驱动电源特性 |
| 插座终端 | 纳入 | 插座用途、RCD适用条件、N/PE配置 |
| 普通设备终端 | 纳入 | 设备铭牌/负荷参数、连续或冲击特性 |
| 配电干线 | 纳入 | 下游负荷汇总、需要/同时系数、上下级保护边界 |
| 电动机终端 | 后续 | 效率、启动方式、启动电流、启动压降、接触器、热继电器及电动机专用保护 |

所有策略共用负荷电流、线路阻抗、电压降、短路、接地故障和热稳定计算内核，不复制物理公式。

## 5. 基础计算输出数据字典

每个结果均保存数值、单位、过程步骤、采用规则、来源状态和适用性。

| 输出代码 | 含义 | 主要下游用途 |
|---|---|---|
| `ib_a` | 计算电流 | 断路器和导体候选 |
| `segment_r_ohm` / `segment_x_ohm` | 单段运行阻抗 | 电压降 |
| `cumulative_voltage_drop_v` | 累计电压降 | 导体筛选 |
| `cumulative_voltage_drop_percent` | 累计压降百分比 | 限值校核 |
| `ik_max_ka` | 保护安装点最大预期短路电流 | Icu/Ics/Icw校核 |
| `ik_min_a` | 线路末端最小短路电流 | 保护动作校核 |
| `if_min_a` | 末端最小接地故障电流 | TN自动切断 |
| `fault_loop_zs_ohm` | 完整故障回路阻抗 | TN自动切断 |
| `peak_current_ka` | 短路峰值 | 峰值耐受校核 |
| `required_phase_thermal_mm2` | 相导体热稳定所需截面 | 导体筛选 |
| `required_pe_thermal_mm2` | PE热稳定所需截面 | PE筛选 |
| `required_breaking_capacity_ka` | 所需最低分断能力 | 断路器候选 |
| `required_action_current_a` | 规定时间内需保证动作的边界 | 脱扣特性校核 |

必须区分：

- 运行工况电阻；
- 最大短路电流所采用的阻抗条件；
- 最小故障电流所采用的较高导体温度条件。

三者不得共用一个无来源的固定R/X。

## 6. 电缆候选生成与判定矩阵

### 6.1 候选生成输入

- `ib_a`；
- 系统额定电压；
- 相制；
- 回路用途；
- 用户允许的导体型号；
- 用户选择的敷设场景；
- 明确的相线、N、PE结构要求；
- 环境温度；
- 成组和土壤条件；
- 总线路长度和本段长度；
- 上游保护类型边界。

### 6.2 判定顺序

| 顺序 | 判定项 | 使用数据 | 结果 |
|---:|---|---|---|
| 1 | 型号和额定电压适用 | 系统电压、型号目录 | 不适用即淘汰 |
| 2 | 结构适用 | 相制、N/PE要求、结构目录 | 不适用即淘汰 |
| 3 | 敷设场景有基础载流量依据 | 型号、结构、敷设方式 | 无依据则无法生成正式候选 |
| 4 | 基础载流量 | 表列载流量 | 形成基础候选 |
| 5 | 环境温度修正 | 温度及修正规则 | 得到修正载流量 |
| 6 | 成组/土壤等修正 | 敷设详细条件 | 得到最终允许载流量 `Iz` |
| 7 | 过载保护关系 | `Ib`、保护设定、`Iz` | 不满足则淘汰组合 |
| 8 | 累计电压降 | 各段R/X、长度、负荷 | 超限则增大截面或淘汰 |
| 9 | 末端故障保护 | `If,min`或`Ik,min`、保护曲线 | 不满足则改变截面或保护器 |
| 10 | 相导体短路热稳定 | 最大故障电流、切除时间/I²t | 不满足则淘汰 |
| 11 | PE热稳定 | PE截面、故障电流、切除时间/I²t | 不满足则改变PE或保护器 |
| 12 | N线条件 | 负荷性质及结构 | 缺失时无法判断 |
| 13 | 最终组合状态 | 所有硬条件 | 通过/不通过/无法判断 |

### 6.3 电缆候选输出

每个候选至少返回：

- 导体型号和额定电压；
- 芯数结构；
- 相线、N、PE截面；
- 基础载流量；
- 各修正系数及修正后载流量；
- 本段和累计电压降；
- 最大/最小故障电流；
- 相线和PE热稳定结果；
- 与每个保护候选的配合结果；
- 淘汰原因；
- 规则编号和资料页码；
- 暂算状态与正式状态。

## 7. 断路器候选生成与判定矩阵

### 7.1 断路器分类

| 类型 | V1用途 |
|---|---|
| MCB | 普通末端小电流回路 |
| MCCB | 干线、配电和较大普通负荷 |
| ACB | 低压总进线或需要相应参数等级的场合 |

MCCB和ACB不是电动机专用设备。D型MCB以及电动机启动、接触器、热继电器的配合放入后续电动机模块。

### 7.2 候选生成输入

- `ib_a`；
- 系统额定电压；
- 安装节点；
- 回路用途；
- 相制、接地系统和N线处理；
- 导体候选的修正载流量 `Iz`；
- 安装点 `ik_max_ka`；
- 线路末端 `ik_min_a` 或 `if_min_a`；
- 要求的自动切断时间；
- 上下级保护器的设计参数；
- 是否需要剩余电流保护；
- 设计参数模式或具体产品核验模式。

### 7.3 判定顺序

| 顺序 | 判定项 | 使用数据 | 结果 |
|---:|---|---|---|
| 1 | 设备类别适用 | 安装节点、额定电流范围、用途 | 不适用即淘汰 |
| 2 | 额定工作电压 | 系统电压 | 不足即淘汰 |
| 3 | 极数和N极处理 | 相制、接地系统、N线要求 | 缺条件则无法判断 |
| 4 | 额定电流/长延时整定 | `Ib` | 形成电流候选 |
| 5 | 壳架电流 | 额定电流/整定范围 | 不适用即淘汰 |
| 6 | 导体过载保护 | `Ib`、`In/Ir`、`Iz`及对应规则 | 不满足则淘汰组合 |
| 7 | 分断能力 | 安装点`ik_max`与Icu/Ics要求 | 不满足即淘汰 |
| 8 | 短时耐受 | 适用节点的Icw和持续时间 | 缺产品参数则无法判断 |
| 9 | 瞬时/短延时动作 | `ik_min`或`if_min`与曲线/整定 | 不满足则改变保护器或导体 |
| 10 | 自动切断 | 故障回路、动作电流和规定时间 | 不满足则淘汰组合 |
| 11 | 导体热稳定 | 产品I²t或可追溯切除时间 | 不满足则淘汰组合 |
| 12 | RCD用途和参数 | 场所、波形、泄漏电流、上下级RCD | 缺条件则无法判断 |
| 13 | 选择性/后备保护 | 上下级准确产品编号、脱扣/整定配置、厂家选择性或级联表、下级安装点`ik_max` | 精确匹配后比较表列极限；缺任一条件则无法判断 |

### 7.4 两种输出模式

#### 设计参数模式

不输出品牌型号，只输出最低或允许范围：

- 设备类别；
- 额定工作电压；
- 额定电流或整定范围；
- 壳架电流等级；
- 极数待确认条件；
- 最低Icu/Ics；
- 必要时的Icw；
- 规定时间内需要满足的动作电流边界；
- RCD用途、类型和额定剩余动作电流条件；
- 尚未完成的产品曲线和选择性校核。

#### 具体产品核验模式

只有录入可追溯产品样本后，才校核：

- 实际Icu/Ics/Icw；
- 实际长延时、短延时和瞬时整定；
- 时间—电流曲线；
- 实际I²t或能量限制数据；
- 上下级选择性和后备保护表；
- RCD动作时间和波形类型。

## 8. 电缆—断路器闭环求解

完整回路不是单向计算，求解器应按以下顺序迭代：

1. 计算 `Ib`；
2. 生成首批断路器电流参数候选；
3. 对每个断路器候选生成满足基础载流量的电缆候选；
4. 对各段电缆进行环境、成组和土壤修正；
5. 删除不满足过载保护关系的组合；
6. 计算全链路累计电压降，必要时增大相关线路截面；
7. 以当前截面重新计算各节点最大短路电流；
8. 计算各线路末端最小短路和接地故障电流；
9. 校核分断能力、自动切断和脱扣特性；
10. 校核相导体和PE短路热稳定；
11. 若截面或保护参数改变，从第4步重新计算；
12. 无新增候选且全部硬条件通过时收敛；
13. 若候选耗尽，输出“无满足组合”及逐项失败原因；
14. 若关键数据缺失，保留已完成结果，整体输出“无法判断”。

求解器必须设置确定性的候选顺序和最大迭代次数。相同输入、规则版本和目录版本必须得到相同结果。

## 10. 状态传播规则

| 情况 | 暂算状态 | 正式状态 |
|---|---|---|
| 已知条件全部满足、暂算通过 | 通过 | 取决于全部采用规则是否已批准 |
| 任一硬条件明确不满足 | 不通过 | 只有对应规则已批准时可正式不通过 |
| 缺少必要输入、产品参数或适用规则 | 无法判断 | 无法判断 |
| 回路超出V1范围 | 不适用 | 不适用 |

上游数据或候选改变后，所有依赖它的下游结果必须失效：

- 负荷变化：电流、导体、压降、保护全部失效；
- 导体截面变化：压降、短路、接地故障和热稳定失效；
- 断路器变化：自动切断、热稳定和选择性失效；
- 变压器参数变化：各节点短路和故障保护结果失效；
- 拓扑或长度变化：该点以下全部结果失效。

## 11. 现有代码复用与重构入口

现有能力不废弃，按以下方式迁移：

| 现有能力 | 完整回路中的归属 |
|---|---|
| `calculate_simple_load_selection` | 负荷计算和首批候选的参考，不再承担完整闭环 |
| `calculate_voltage_drop`及快速页压降逻辑 | 单段压降内核，外层增加逐段累计 |
| `calculate_transformer_lv_nameplate_impedance` | 电源阻抗模块 |
| `calculate_transformer_feeder_three_phase_short_circuit` | 重构为通用节点短路计算 |
| `calculate_tn_fault_loop_chain` | 故障回路分段累加内核 |
| `calculate_cable_fault_loop_impedance` | 线路段相—PE阻抗内核 |
| `calculate_tn_earth_fault_protection` | 节点自动切断校核 |
| `calculate_pe_thermal_withstand` | PE热稳定校核 |
| `catalog.py`现有表列目录 | 拆为规则目录、通用参数目录和产品目录 |

新统一入口建议为：

```python
calculate_complete_circuit(
    circuit,
    rules,
    generic_catalog,
    product_catalog=None,
) -> CompleteCircuitOutcome
```

候选器独立接口：

```python
generate_cable_candidates(segment, context, rules, catalog)
generate_breaker_candidates(node, context, rules, catalog)
verify_component_combination(circuit, combination, rules, catalog)
```

首版代码接口已经拆分为：

```python
generate_cable_candidates(
    request: CableSelectionRequest,
    rules,
    catalog,
) -> Outcome

generate_breaker_candidates(
    request: BreakerSelectionRequest,
    rules,
    catalog,
) -> Outcome
```

电缆候选器只判定结构、基础载流量和温度/成组/土壤修正；断路器候选器只判定通用设计参数、`Ib≤In≤Iz`、极数条件、Icu及当前已有的MCB B/C保证动作边界。两者都必须保留淘汰原因，且都不能单独宣布“完整回路可采用”。

组合求解器首版接口：

```python
solve_complete_circuit_combinations(
    request: CombinationSolverRequest,
    rules,
    catalog,
) -> Outcome
```

首版对每组电缆重新计算逐段/累计电压降、各节点短路和相—PE故障电流，再按保护安装点与被保护线路末端分别筛选断路器参数。已知硬条件失败的组合进入淘汰清单；缺产品I²t、Ics/Icw、脱扣整定、选择性或RCD条件的组合只能标记为“可继续但未闭合”。当前排序只为保证相同输入输出顺序稳定，不代表经济最优或正式推荐。

上下级保护按被保护线路段顺序形成相邻保护点对。单保护点回路没有平台内部的选择性配合对象，不列选择性缺失项。多保护点回路在通用参数模式下逐对输出“无法判断”；不得用上下级额定电流之比代替厂家选择性结论。只有厂家证据与双方产品编号及脱扣/整定配置完全匹配时，才比较下级安装点`ik_max`与表列选择性极限、级联或后备保护极限。

## 12. 页面设计边界

新建 `/complete-circuit`，不继续扩张 `/quick`。

页面按工程逻辑分为：

1. 电源；
2. 回路拓扑；
3. 负荷；
4. 各线路段；
5. 各保护节点；
6. 计算和候选组合；
7. 未完成校核与依据。

普通用户只看到必要字段；环境、成组、土壤、产品曲线等放入对应线路段或保护器的“专业条件”，不能堆入一个全局高级选项区。

## 13. V1验收样例

首个完整样例固定为：

```text
S11-M 400kVA变压器
→ KTA母线槽 5m
→ 低压总柜
→ YJV干线 50m
→ 分配电箱
→ YJV或BV末端线路 30m
→ 普通单相或三相负荷
```

验收必须覆盖：

- 每段R/X和累计R/X；
- 各节点最大短路电流；
- 末端最小接地故障电流；
- 分段和累计电压降；
- 至少两组电缆/断路器候选的淘汰过程；
- 一个通过样例；
- 一个电压降导致增大截面的样例；
- 一个末端故障电流不足的样例；
- 一个分断能力不足的样例；
- 一个PE热稳定不满足的样例；
- 一个缺少产品曲线而“无法判断”的样例；
- 相同输入重复计算结果完全一致；
- 上游修改后下游历史正确标记为过期。

## 14. 实施顺序

1. 建立纯Python回路、节点、线路段和候选数据结构；

## 15. 当前资料缺口

现有资料足以开始数据模型和计算链开发，但以下项目会限制完整正式结论：

- BV、YJV更多芯数和敷设方式的完整基础载流量；
- 独立PE、PEN及更多YJV结构的相—PE阻抗；
- 相导体短路热稳定的完整规则与参数；
- MCCB、ACB通用设计参数边界及具体产品曲线；
- 上下级选择性、后备保护和I²t产品数据；
- RCD动作时间、实际泄漏电流和上下级配合数据；
- 谐波及明显不平衡负荷下N线处理；
- 一个真实项目完整铭牌和线路数据。

缺口不阻塞架构开发，但对应校核项必须返回“无法判断”，不得用经验默认值补齐。

## 16. 多会话评估

本阶段继续采用一个主会话顺序开发。

原因：

- 回路模型、候选器和校核器共享同一数据结构；
- 开发顺序高度串行；
- 多个任务会同时修改`engine.py`、`catalog.py`和数据库模型；
- 规范状态和参数目录需要统一解释；
- 之前多会话产生了反复授权、上下文重复和文件冲突风险，总Token并未降低。

只有在完成计算链里程碑后，如需要一次只读的公式或测试审查，才临时启动一个不修改共享文件的审查任务。退出条件是出现权限不稳定、重复读取或需要修改共享核心文件时立即回归主会话。
