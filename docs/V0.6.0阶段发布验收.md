# V0.6.0阶段发布验收

## 发布目标

把V0.5.0已经闭合的单台三相异步电动机直接启动计算变成可保存、可追溯、可导出的工程成果，并让完整回路复用同一电动机额定/启动电流引擎。

## 纳入范围

- `/motor`可选择项目、回路编号和名称；不选择项目时仍保持无保存快速计算；
- 同一项目同一电动机回路输入变化时修订号递增，旧计算记录标记过期且不覆盖；
- 版本详情冻结输入、额定/启动电流、主电缆、主保护控制组合、启动电压和未闭合项；
- 版本级PDF与Excel从冻结快照生成，导出时不重新计算；
- 完整回路负荷类型为电动机时，额定电流和启动电流调用与`/motor`相同的纯计算引擎，并写入推导快照。

## 验收样例

- 0.12kW、30kW、200kW均可保存、打开版本详情并导出PDF/Excel；
- 同一回路长度改变后旧版本显示已过期；
- 不选择项目时`/motor`不写数据库；
- 完整回路30kW电动机的设计电流与电动机引擎额定电流一致；
- 全量测试、HTTP页面、公开文件边界检查通过。

## 不纳入范围

- 星—三角、自耦、软启动、变频启动和多电动机群；
- 自动生成采购订单或施工图；
- 未取得实际机械负载资料时判定电动机端子启动转矩通过；
- 未取得上下级产品组合证据时判定选择性或后备保护通过。
