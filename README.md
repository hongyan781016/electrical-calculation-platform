# 电气工程计算自动化平台

面向具备一定电气基础的用户、运行在 Windows 本机的低压回路计算工具。

当前开发版本为 `v0.5.0`。本版集中闭合0.12～200kW、4极、50Hz三相异步电动机直接启动回路：每个目录功率均形成唯一主电缆和主保护/控制组合，并联合复核运行压降、启动母线电压、安装点短路、末端故障、分断能力及相线/PE热稳定。复杂多电源网络和DWG自动识别仍不在本阶段范围内。

## 三种工作流

- **快速计算**：用户只填写功率或电流、相制、长度等少量已知条件，系统自动推导和查表，输出电缆及MCB/MCCB通用参数候选；条件完整时继续完成三相短路、Icu、TN接地故障、相线/PE热稳定和极数暂算，并以已核验产品样本补足脱扣及限流参数（仅作等效参数参考，不构成品牌推荐）。
- **电动机回路**：用户选择厂家目录功率或补充实际铭牌参数，系统完成额定/启动电流、电缆、压降、短路、接地故障、热稳定及控制保护器件的联合初选。
- **图纸核验**：图纸作为既有设计条件，系统沿“变压器低压出口 → 低压柜 → 分配电箱 → 用电设备”逐段复算，分别判断原电缆和原断路器。替代候选单独显示，不能代替原设计合规结论。

## 0.4kV 回路计算向导

打开 `http://127.0.0.1:8765/quick`，无需新建项目或导入 Excel。页面支持“单台设备、同类负荷汇总、配电箱或干线”三种回路角色，可按 kW、kVA 或已知电流计算。单台设备会按负荷资料自动调整适用相制；同类单相设备可按三相均衡汇总，但必须确认相负荷分配。

kW 可明确为已经确定的计算功率，或安装功率。安装功率模式必须由用户填写需要系数，系统不会猜测默认值。kW 模式可填写铭牌/厂家功率因数；未填写时按所选设备的功率因数范围下限保守初选。“其他/不确定”负荷必须填写功率因数才能由 kW 计算电流。

快速页依据项目内 19DX101-1 的已核实表格给出不绑定品牌的 MCB 设计参数候选，包括额定电流、额定电压、电流规格等级及分断能力档位。D型MCB及MCCB的具体产品脱扣/整定参数归入后续电动机模块。回路位于变压器0.4kV低压出口时，可按表15.7选择变压器容量和铭牌uk%速查短路电流；只知道容量时显示表列范围并按上限暂选分断能力。RCD 按用途/场所给出剩余动作电流候选，并按用户确认的剩余电流波形给出类型候选；具体产品动作时间仍待核验。

载流量表或必要校核未批准时，页面显示“基础初选”，正式状态保持“无法判断”。BV 穿管会根据普通回路相制自动匹配2根或3根载流导线的表列工况；YJV按用户选择的三芯、四芯或五芯结构匹配已核实载流量表。高级条件可选择实际环境空气温度或地下温度，系统按19DX101-1表6.22或表6.24自动修正载流量并重新选择截面。对TN-S/TN-C-S铜芯回路，系统在已知变压器、线路长度和电缆结构后自动推导PE截面及故障电流；RCD用途明确时联动确定全部带电导体的开断极数。快速页只有一个保护点，因此上下级选择性标记为“不适用”，存在多级保护时转完整回路模块校核。本页面不会写入项目、回路或计算历史。

高级条件中只需填写线路长度即可继续计算电压降。系统根据最小满足截面，从已核实的19DX101-1表格自动查取 R/X；普通低压线路自动采用5%，供给有照明负荷的低压线路按手册表6.2-6的3%～5%范围取3%作保守暂算。该限值规则目前已核实、未批准。

## 电动机回路 v0.2

打开 `http://127.0.0.1:8765/motor`。本阶段处理0.4kV三相异步电动机单机直接启动回路；用户可从厂家目录功率列表选择，目录未覆盖时再填写铭牌功率、电流、功率因数、效率和启动倍数。380V与400V按本项目约定视为同一产品应用档，但页面保留实际系统电压参与计算。

默认快速工况为YJV四芯3相＋PE、槽盒50m、空气40℃、1层1根、SCB11 630kVA/uk=6%、上级系统短路容量100MVA。用户只需选择功率、额定电压、极数、线路结构、敷设方式和长度；知道真实项目参数时可展开替换默认工况。页面会明确说明默认值只是快速初选条件，不代表现场电源。

当前4极厂家参数目录覆盖0.12～200kW。0.37～200kW按施耐德EasyPact CVS＋TVS的380～415V直接启动1类配合表精确功率行，形成MA短路保护断路器、AC-3接触器、独立热继电器和电缆联合方案；0.12～0.25kW按施耐德TeSys GV2＋LC1D的400/415V直接启动2类配合精确行形成一体化热磁保护方案，本项目按已确认边界将380V归入同一产品应用档。每个列表功率均须完成电流、压降、短路、接地故障及相线/PE热稳定后才显示采购参数，目录外功率不插值。

系统按同一条候选链完成：额定与启动电流 → 电缆基础载流量及修正 → 运行压降 → 末端短路和TN接地故障 → 相导体及PE热稳定 → 启动端电压 → 保护和控制器件。主结果只推荐满足当前已知条件的最小电缆；其他截面放入复核明细，不要求用户自行在多个候选中猜选。

保护结构严格区分为两种：具有电动机过载保护的MCCB与接触器组成一体化路线，或短路保护器件、接触器与独立热过载继电器组成分立路线。同一主方案不会重复配置两套过载保护。断路器长延时整定按 `Ib ≤ Ir ≤ Iz` 和实际产品档位确定；热继电器以电动机额定电流为整定目标，并验证产品可调范围。

产品参数仅作为带来源的候选参考，不等同品牌推荐。当前成套表明确的是制造商1类配合；2类配合、上下级选择性和实际启动时间仍单列为深化项，不冒充已经完成。

## 完整低压回路

打开 `http://127.0.0.1:8765/complete-circuit`。页面支持“快速设计”和“既有设计核验”两种任务，当前边界为单电源、三相、三段放射式回路：变压器低压出口 → 低压馈线柜 → 下级配电箱 → 用电设备末端。

用户填写变压器容量和 `uk%`、末端负荷、三段线路长度、YJV结构及敷设方式；上级系统不知道时可明确采用100MVA参考工况。系统不要求用户填写R/X、累计阻抗、故障回路阻抗或短路电流，而是根据现有数据表和输入条件推导：

- 上级系统短路容量与变压器表列R/X解析；
- 各线路段负荷流、载流量和累计电压降；
- 各节点最大三相短路、最小相—N短路和TN相—PE故障电流；
- 既有电缆、断路器的 `Ib≤In≤Iz`、分断能力和自动切断条件；
- PE最小截面、相导体/PE热稳定允许约束；
- 上下级选择性/后备保护的证据完整性检查。

快速设计会收敛为一组当前主方案；既有核验会先评价用户填写的原部件，再单独给出替代主方案。电缆候选在进入组合求解前先执行PE最小截面硬条件，避免把明显不合格的小截面显示给用户选择。没有准确产品曲线、I²t或厂家配合表时，对应项目显示“无法判断”，不会猜测通过。

计算完成后可保存到项目。每次保存都会冻结用户输入、系统推导值、原设计核验、主方案、警告及依据快照；输入未变化时不会虚增网络修订，输入变化时旧计算版本保留并自动标记为“已过期”。历史版本可独立查看，并可导出对应的PDF计算书和Excel成果表；导出阶段不重新计算。

## 已实现的计算基础

- 负荷计算与电缆/保护器件配合暂算
- 电压降计算与按回路类型自动采用的限值暂算
- 三相对称短路电流简化计算与分断能力暂算
- 多段完整放射式回路的逐节点短路与接地故障计算
- 图纸原部件复核与独立替代候选
- 电缆和保护器件组合求解
- 三相异步电动机直接启动回路及两类保护结构初选
- 计算依据的待核实、已核实、已批准状态管理
- 完整回路项目保存、不可覆盖版本、失效标记和版本级PDF/Excel导出

旧版单回路项目、Excel批量导入和对应历史仍保留兼容；V0.4的正式入口是完整回路项目版本。真实工程图纸只用于本地回归检验，不随公开版本发布。

> **重要：** 规范、手册、产品样本和真实图纸不随公开仓库发布。平台内置数据保留来源定位和状态；关联依据未批准或必要校核未完成时，正式状态保持“无法判断”。

## 启动

### 最简单的方式

首次安装完成后，直接双击项目根目录的 `启动应用.cmd`。程序会：

- 检查项目虚拟环境；
- 判断应用是否已经运行；
- 检查端口是否被其他程序占用；
- 服务就绪后自动打开快速计算页面；
- 启动失败时在窗口中显示中文原因。

停止应用可双击 `停止应用.cmd`。启动窗口仍在时，也可以在窗口中按 `Ctrl+C`。

### 首次安装

在项目根目录的 PowerShell 中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

安装后双击 `启动应用.cmd`，或执行：

```powershell
.\.venv\Scripts\python.exe run.py
```

平台默认打开 `http://127.0.0.1:8765/quick`。如果应用已运行，再次执行启动命令只会打开现有页面，不会重复占用端口。无需自动打开浏览器时：

```powershell
.\.venv\Scripts\python.exe run.py --no-browser
```

如8765端口被其他程序占用，可临时使用：

```powershell
.\.venv\Scripts\python.exe run.py --port 8766
```

### 在 VS Code 中运行

用 VS Code 打开整个项目文件夹，不要单独打开 `run.py` 或HTML模板。仓库内的 `.vscode` 配置会固定使用项目虚拟环境：

1. 打开“运行和调试”；
2. 选择“启动电气计算平台”；
3. 按 `F5`；
4. 保持集成终端运行。

也可以在VS Code终端执行上述Python命令。Jinja模板必须由FastAPI渲染，不能使用Live Server或直接双击`quick.html`。

本机项目库默认位于 `data/electrical_calc.db`。如需使用其他数据库，可在启动前设置 `ELECTRICAL_CALC_DB`。

## 建议工作流

1. 只知道负荷条件并准备采购时，使用“快速计算”。
2. 已有图纸并需要判断原设计时，使用“图纸核验”。
3. 先查看原图设计复核，再查看独立替代候选；两栏结论不得互换。
4. 对“无法判断”项目补充铭牌、产品曲线或厂家配合表后再复核。

## 数据约束

- 内部固定使用 V、kW、A、m、Ω、Ω/km、kA 和百分数。
- 缺失、不适用和数值 0 严格区分。
- 未给出的参数不会被默认值替代。
- 三个模块共享同一回路输入；任何更新都会递增回路修订号。
- 每次计算保存输入、依据、过程、结果和警告的完整快照。
- 只有关联规则全部为“已批准”时，平台才会把暂算通过/不通过提升为正式状态。

## 测试

```powershell

```

测试覆盖快速计算、完整回路、电动机目录与回路计算、缺失输入、适用范围、逐节点故障电流、图纸原器件核验、替代候选隔离以及网页主流程。
