# 工程计算自动化

## 项目目标

将常用工程计算整理为可复用、可校核、可追溯的计算工具，减少重复录入和手工计算，提高方案比较、设计复核和成果输出效率。

首期覆盖：

- 负荷计算
- 管径计算
- 设备选型

## 核心原则

1. **结果可复核**：不仅给结论，还要显示输入条件、计算过程、采用参数和单位。
2. **数据只录一次**：同一项目的房间、系统和设备参数应能被多个计算模块复用。
3. **计算与选型分开**：先得到设计需求，再按设备库筛选型号，避免把厂家参数写进计算逻辑。
4. **规范参数可追溯**：规范条文、设计手册和厂家样本作为独立依据保存；未核实的数据不进入正式计算。
5. **先解决高频工作**：优先自动化规则清楚、重复度高、人工容易出错的计算。
6. **保留人工判断**：工具输出“计算结果 + 校核信息”，不替代设计人员最终判断。

## 首版产品形态

建议首版采用：

- Excel/CSV 作为批量输入、输出格式
- Python 作为计算核心
- 简单网页界面作为后续入口
- 每次计算生成一份可存档的计算书

首版不做账号、云端协同、复杂权限和大型数据库。

## 建议的第一个可用版本

第一版只做一条完整链路：

> 标准化输入 → 单项计算 → 结果校核 → 计算书导出

优先选择一个高频、公式明确、已有手算样本可对照的模块。建议从“给排水管径计算”或 David 当前重复最多的单项计算开始，而不是同时开发全部模块。

## 完成标准

一个计算模块只有同时满足以下条件才算可用：

- 输入项、单位、必填条件清楚
- 参数来源已核实并记录
- 中间过程能够查看
- 异常值和适用范围能够提示
- 与至少 3 份人工计算样本核对
- 能导出便于复核和归档的结果
